# 2026-08-31 开发日志

## 本阶段结果

- 新增 `npm run prices` 批处理入口，支持 `plan`、`inspect`、`validate` 和 `apply` 四个命令。
- `plan` 按品类和价格类型生成缺口、推荐运行内存 + 存储组合及搜索词；`inspect` 仅读取一个明确商品页，返回标题、容量、候选价格和国行 / 二手信号。
- `validate` 检查设备 ID、价格类型、人民币范围、受信域名、存储配置、成色与采集日期；`apply` 只把通过验证且正式库尚未覆盖的记录写入 `price-observations.json`。
- 中文同步脚本合并已审核观察值；数据门禁动态核对观察文件，避免以后每新增一条价格都修改同步逻辑和硬编码数量。
- 同步脚本进一步保留未变化 computed 字段和元数据日期，空观察文件重跑后主库与来源登记哈希保持不变。
