# 2026-08-31 开发日志

## 本阶段结果

- 新增 `npm run prices` 批处理入口，支持 `plan`、`inspect`、`validate` 和 `apply` 四个命令。
- `plan` 按品类和价格类型生成缺口、推荐运行内存 + 存储组合及搜索词；`inspect` 仅读取一个明确商品页，返回标题、容量、候选价格和页面关键词信号；识货页同时列出可选 SKU，链接带 `skuId` 时直接解析选中规格、当前显示价与页面规格价。
- `validate` 检查设备 ID、价格类型、人民币范围、受信域名、运行内存 + 存储配置、成色与采集日期；`apply` 只把通过验证且正式库尚未覆盖的记录写入 `price-observations.json`。
- 中文同步脚本合并已审核观察值；数据门禁动态核对观察文件，避免以后每新增一条价格都修改同步逻辑和硬编码数量。
- 同步脚本进一步保留未变化 computed 字段和元数据日期，空观察文件重跑后主库与来源登记哈希保持不变。
- `inspect --render` 可调用本机 Chrome/Chromium 检查受信动态商品页；九机页面会返回当前库存的价格、成色、产品配置、库存编号、电池健康、维修记录、型号、国行版本、验机摘要和售罄状态，减少人工复制与误取关联商品价。
- 九机动态检查同时列出最多 50 条同款库存链接及其配置、成色、标价和电池健康，售罄入口可直接切换到活动库存后再做完整验机核对。

## 边界

- `inspect` 只在识货链接明确携带 `skuId` 时选择对应规格；九机动态页需显式使用 `--render`，且依赖本机 Chrome/Chromium。浏览器不可用、页面结构变化、未指定 SKU 或配置与设备不一致时继续人工复核。
- MacBook 快照代表中国大陆电商购买渠道，不额外声称来源页未写明的硬件地区版本；不同运行内存、存储和显示屏选配不得互相套价。
- 当前价仍是特定配置和日期的静态参考，不代表长期售价或实时全网最低价。
- 二手价是一机一价快照；商品售出后仍只代表采集日参考，不能描述为当前可购买行情。
- 识货页面将 iPhone 16 Pro Max 的 10162.44 元结构化为整数人民币 10162 元，原始小数价格保留在 `rawText`。
- 第三方补录的 MacBook 首发价是绑定明确配置的历史参考；若未来取得 Apple 中国商店归档，应以官方证据替换，不把同系列起售价直接套给不同芯片档位。
