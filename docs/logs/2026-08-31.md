# 2026-08-31 开发日志

## 本阶段结果

- 新增 `npm run prices` 批处理入口，支持 `plan`、`inspect`、`validate` 和 `apply` 四个命令。
- `plan` 按品类和价格类型生成缺口、推荐运行内存 + 存储组合及搜索词；`inspect` 仅读取一个明确商品页，返回标题、容量、候选价格和国行 / 二手信号。
- `validate` 检查设备 ID、价格类型、人民币范围、受信域名、运行内存 + 存储配置、成色与采集日期；`apply` 只把通过验证且正式库尚未覆盖的记录写入 `price-observations.json`。
- 中文同步脚本合并已审核观察值；数据门禁动态核对观察文件，避免以后每新增一条价格都修改同步逻辑和硬编码数量。
- 同步脚本进一步保留未变化 computed 字段和元数据日期，空观察文件重跑后主库与来源登记哈希保持不变。

## 边界

- `inspect` 只提供候选证据，不自动选择多 SKU 页面中的最终价格；动态页面没有直接暴露价格时继续人工复核。
- 当前价仍是特定配置和日期的静态参考，不代表长期售价或实时全网最低价。
- 二手价是一机一价快照；商品售出后仍只代表采集日参考，不能描述为当前可购买行情。
- 识货页面将 iPhone 16 Pro Max 的 10162.44 元结构化为整数人民币 10162 元，原始小数价格保留在 `rawText`。
