# DeviceScope 后续建议与范围

更新日期：2026-10-07。当前成果以 [项目计划](PROJECT_PLAN.md) 和 [日志](logs/2026-10-07.md) 为准。本文区分已实施要求与未批准建议，不自动授权采集、付费调用或新功能。

## 原建议的实际进展

| 原方向 | 当前状态 |
| --- | --- |
| 自选跨品牌比较 | 已实现；同品牌/跨品牌统一“产品对比”，按类别再逐台选择品牌、系列、型号；不再是独立功能导航 |
| 非 Apple 平板/笔记本 | 已多批扩容，不再是未开始试点；仍未全量覆盖历史型号与配置 |
| 更多设备类别 | 手表、手环已接入八品牌适用样本，手机/平板/笔记本共五品类；不得继续列为未开发 |
| 图片与配色 | 已加入主图、配色/款式和放大，缺图不伪造；商业许可仍未知 |
| 配置选择器 | 按用户最新要求取消；各配置价格和参数差异在字段中逐项说明，不恢复旧的“可折叠配置控件”建议 |
| 同款归并 | 17 个人工确认组，38 条款式来源归为 17 型号；保留原证据、报价和不同硬件分支 |
| 3D 产品视角 | 用户取消，不继续开发 |
| AI 真实效果与线上可用性 | 需分别验收；模拟协议成功率和本地构建不能证明推荐准确率及手机端网络可用 |

当前有 991 条原始记录、970 个目录型号；近五/十年范围仍 partial，数量不证明全市场完整。缺主图 8 条、部分颜色图和规格/报价缺失；至少一笔有效当前价/二手价覆盖 68/97 型号。照片有来源不等于许可。

## 后续主线

1. P0：完成本次发布及关键导航检查，明确预览访问保护和用户端网络可用性。
2. P1：补年度/品牌/品类目录证据与差集；优先修正真实型号/版型错误，其次热门缺失规格与主图。不以推测补齐国行数据。
3. P1：热门配置当前价及过旧报价队列。复用已有工具、缓存和批次校验，二手价保持低优先级轻量参考，不追求实时全网最低价。
4. P1：经授权少量真实 DeepSeek 代表样例；分别记录候选召回、设备/报价绑定、人工文字事实、需求满足、Token、耗时和 retry/fallback。没有失败证据不新建复杂评分。
5. P2：同条件测评小样本。DXOMARK 区分协议版本；新评科技、小白测评等需要真实来源和可复用条件，不将像素/容量当作体验评分。

## 仍待选择的功能

| 建议 | 首版边界 |
| --- | --- |
| 基于现有设备的换机判断 | 输入痛点与目标，允许“不必换/证据不足”；实际回收价不能用二手零售价代替 |
| 顾问历史与对比导出 | 先本地保存/清除与 Markdown，不默认扩到账号系统 |
| 关键参数证据入口 | 复用来源，不重新建设整套追踪平台 |
| 真实产品对比 AI | 服务端由 ID 重建事实和报价绑定后才评估接入；当前仍是规则 |
| 同条件续航/游戏证据 | 记录测试协议、系统及条件，先小样本，不直接全品牌排行榜 |
| 数据库迁移 | 只有更新协作、查询或运行时需求证明有收益时评估，当前不是发布前置条件 |

不自动建设账号系统、复杂多维推荐/总榜、全网实时价格、无目标抓取或 3D。新功能需单独明确范围与验收，不把整张建议表当作已批准待办。
