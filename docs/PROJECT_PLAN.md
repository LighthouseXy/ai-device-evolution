# DeviceScope / 数码观察站项目计划

更新日期：2026-07-23

## 项目定位

DeviceScope / 数码观察站是一个电子设备代际演进分析平台，面向需要理解设备规格变化、代际差异和选购权衡的用户。它把可追溯的设备资料、可视化观察和 AI 辅助建议组织为可验证的产品链路，而非静态参数表。

第一阶段以 Apple 设备作为样本范围，覆盖 iPhone、iPad 和 MacBook；这不代表项目已支持多品牌。数据层当前是本地结构化 JSON 数据源和来源追踪模型，不是 PostgreSQL、MySQL 或 MongoDB 等数据库系统。

## 目标用户与价值主张

- 对换机、选购或设备演进感兴趣的用户：从参数堆叠中快速理解代际变化与取舍。
- 需要横向研究设备的内容创作者或产品研究者：按类别、系列和指标查看真实结构化数据。
- 希望获得建议但仍需要可解释结论的用户：设备顾问同时呈现推荐理由、注意事项和权衡点。

## 能力边界

- `/compare` 和 `/trends` 的分析基于本地规则与真实结构化数据，不是实时模型调用。
- AI 顾问可走真实 DeepSeek 链路，也保留 rules fallback；DeepSeek 已有真实复测证据，但不承诺长期稳定。
- 缺失字段按缺失状态展示，不伪造参数或把推断结果包装成官方事实。
- 后续可评估迁移到真实数据库和扩展更多品牌/类别，但两者均非当前已实现能力。

## 已完成能力

- 本地结构化 JSON 数据模型：第一阶段覆盖 63 台 Apple 设备，运行时默认读取中国简体中文主数据，区分官方参数与 computed 字段，并保留来源、置信度和英文官网快照。
- 数据质量门禁：校验 21 个严格比较组、直接前代、核心字段覆盖、主数据与来源登记对应关系，以及字段 URL、来源类型和地区可审计性。
- P6 中文官网数据收口：58 台设备的规格已重新从 Apple Support 中国简体中文技术规格页采集，58 台设备首发价统一落到 Apple 中国 Newsroom 一方来源；英文官网主数据与来源登记按原始哈希独立保留。
- P7 MacBook Pro 芯片档位拆分：将 5 条合并的 Pro / Max 记录拆为 10 条独立配置；14 英寸与 16 英寸的 Pro、Max 已成为独立比较系列。英文快照保持不变。
- P8 代际升级评分收口：13 条带直接前代引用的后续代际均已按既有可解释口径完成 1–10 分评分，`pendingGenerationUpgrades=[]`；同时修正 iPad Air / iPad Pro 中文官网共享脚注导致的屏幕尺寸串值。
- 真实数据页面：首页、设备库、设备详情、代际对比、趋势观察和 AI 顾问已完成 v2 前端重构。
- 代际对比：选择器拆分为设备大类（iPhone / iPad / MacBook）与产品系列；iPhone 按数字、Pro、Pro Max、Plus、mini、SE 分类，iPad / MacBook 保留完整型号。
- 代际对比展示：所有比较组均按最新一代在左排序，移除独立变化列，仅在最新一代相较直接前代有变化时于最新值后标记变化。
- 趋势观察：类别、系列、分析维度和范围筛选，以及趋势图、对比表和关键变化展示。
- AI 观察：`/api/ai-analysis` 支持总结、预测、购买建议和字段解释；无模型 key 或调用失败时使用本地规则分析，缓存生成链路已完成验证并具备缓存数据基础。
- AI 设备顾问：`/api/device-advisor` 支持 OpenAI / DeepSeek provider，失败时回退规则推荐；输入覆盖预算、设备类型、性能偏好、使用场景、成色、续航、接口/生态需求。
- AI eval 闭环：评测结果写入 `.eval-results/`，dev-only 看板可读取、切换并展示 KPI、样本明细和失败原因。
- 设备顾问可用性：预算校验、错误提示、四态结果区、推荐层级、场景快捷项和提交前输入摘要。
- 回归保护：覆盖 fallback 场景、API 错误路径和 `maxResults` 边界。
- 本地开发适配：开发服务使用 Webpack + polling，以规避当前环境下的 `EMFILE` watcher 问题。

## 技术架构

- 应用层：Next.js App Router、React、TypeScript 和 Tailwind CSS。
- 数据层：本地结构化 JSON 数据源；`SpecField` 记录来源 URL、来源类型、置信度和验证时间，计算字段以 `computed` 区分。
- 分析层：趋势和代际对比读取真实结构化数据，并以本地规则生成稳定的解释与摘要。
- AI 层：AI 观察与设备顾问可选择 OpenAI / DeepSeek provider；异常、无 key 或不合规输出时回退本地 rules fallback。
- 评测层：设备顾问评测结果写入 `.eval-results/`，由 `/dev/device-advisor-eval` 这个 dev-only 页面展示。

## 后续路线

### 高优先级

- **首发价缺口核验**：仅在 Apple 中国官网发布明确独立配置报价后，补充 3 条仍为空的 MacBook Pro 首发价；不使用推断价或第三方价格。
- **真实模型联调面板**：为 AI 观察和设备顾问增加可控的模型测试入口或调试脚本，验证真实 key 下的输出质量。
- **设备顾问样例集**：沉淀常见用户问题，例如“预算 5000 买 iPad 学习”“旧 iPhone 换机”“MacBook 剪辑开发”等，作为推荐质量基线。
- **AI 缓存质量抽检**：对已生成缓存 entry 做抽样检查，标记可直接展示、需重生成、需改 prompt 的类型。

### 中优先级

- **设备对比导出**：把当前筛选下的趋势和对比摘要导出为 Markdown 或图片，便于项目展示。
- **设备顾问历史记录**：保存最近几次顾问输入和结果，方便用户比较不同预算/偏好。
- **来源追踪展示增强**：在关键参数上补“查看来源”入口，突出数据可信度。

### 低优先级

- **更多设备类别**：Apple Watch、AirPods、Mac mini 等，以及后续可能纳入的其它电子设备品类，等当前第一阶段体验稳定后再扩展。
- **更复杂的推荐解释**：例如总分拆解图、偏好雷达图；当前阶段先保持文本可读。
- **完整端到端 HTTP 测试**：当前已有路由层脚本，后续如项目测试体系成熟再补。
- **真实数据库迁移评估**：当数据规模、并发访问或编辑工作流需要时，评估迁移到数据库系统的成本与收益。

## 当前风险

- 全品类当前价与二手价尚未采集；预算推荐当前使用 Apple 中国大陆首发价和规则降级。
- 中文官网没有明确写出的 30 个旧字段未继续继承，包括部分普通型号刷新率，以及“没有 HDMI / SDXC”等否定项；这些字段保持缺失，不做推断补值。
- `macbook-pro-16-m2-max-2023`、`macbook-pro-14-m4-max-2024`、`macbook-pro-16-m4-2024` 的 Apple 中国官网新闻稿未明确列出独立配置首发价，字段保持为空并显示“待补充”。
- `ipad-air-m4-2025` 为保持现有路由稳定暂时保留旧内部 ID，展示年份已按 Apple 中国官网修正为 2026。
- 真实模型效果仍需持续复测，不能把 rules fallback 结果包装成最终 AI 能力。
- 回归脚本使用 TypeScript transpile + 自定义加载器，模块解析变化时需要同步维护。
- 本地 dev server 使用 Webpack + polling 规避 watcher 问题，但性能会比 Turbopack 慢。
