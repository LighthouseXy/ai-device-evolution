## 已实现的产品链路

- 设备库、同品牌/跨品牌对比、趋势与首页统一使用整理后的目录；旧设备路径仍能读取对应归并型号。
- 同款价格、材质、重量和配色按原始款式保留；NFC、蜂窝网络、尺寸、芯片、柔光屏及真实代际差异保持独立。
- 各品类使用适用字段；穿戴增加健康/运动、定位、蜂窝网络、兼容性、表壳/表带等，不套用手机内存逻辑。
- 配置价格在首发/当前/二手字段逐项列示；内存/存储并非笛卡尔积，CPU/GPU/芯片差异在对应字段标注。二手价保持轻量参考，缺失不伪造。
- 图片配色可切换和放大；没有准确颜色图时保留缺失状态，不给通用图猜颜色。
- 参数详情维持双列卡片，长说明按原文条目正常展示，保持稳定分区与统一正文；后置总述仅在确认由镜头分项覆盖时去重。

## AI 顾问现状与边界

本地按品类、明确接口与配置下限、预算及新旧报价筛选，增加有限价位/品牌覆盖；最多 12 个候选、每机最多两笔代表报价、最终最多 3 台。候选不因同款配色重复挤占席位，仍保留原始款式及报价事实。

模型返回中文 `answer`、设备 ID、逐项对应报价 ID 和内部 confidence；服务端校验归属并补齐设备/价格。整份有效输出为 AI，失败整份回退规则，不混接残缺 AI 内容。DeepSeek 非思考模式、900 输出 token、每次 15 秒、最多一次重试；OpenAI 没有该重试流程。绑定检查与有限正文一致性拦截不是完整语义事实核验。

`/compare` 与 `/trends` 使用本地规则；真实代际 AI 仍未接入。现阶段没有新增付费模型调用；26 个历史 offline 样例和 20 个模拟 API 场景不能当作当前模型正确率、Token/耗时或长期稳定性。真实样例验收需另行授权。
